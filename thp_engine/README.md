# THP Surrogate Model

A data-driven surrogate model for Tubing Head Pressure (THP) prediction in vertical oil wells.
Built as part of ongoing research at the Federal University of Technology, Minna, Nigeria.

---

## What this is

This project builds an open-source Python alternative to commercial well performance tools
(PIPESIM, PROSPER) for computing tubing head pressure. It combines:

- A **physics engine** implementing the Poettmann-Carpenter gradient-traverse method
- A **synthetic dataset** of 9,411 well cases generated by the physics engine
- A trained **XGBoost surrogate model** (R² = 0.9991, MAE = 6.99 psia)
- A **prediction API** and **Streamlit demo app**

## Project structure

```
thp_engine/
├── pvt.py                  # PVT correlations (Rs, Bo, z-factor, Bg)

├── tune_and_evaluate.py    # Hyperparameter tuning + full evaluation
├── save_model.py           # Exports final trained model
├── validate_example716.py  # Validates engine against Ahmed (2010) Example 7-16
├── app.py                  # Streamlit demo app
├── thp_model.joblib        # Trained XGBoost model (ready to use)
├── model_meta.json         # Model metadata and parameter ranges
├── synthetic_dataset.csv   # 9,411 training cases
└── validation_note.md      # Documents z-factor discrepancy with textbook
```

## Correlations used

| Property | Correlation |
|---|---|
| Solution GOR (Rs) | Standing (1947) |
| Oil FVF (Bo) | Dake (1978) form of Standing |
| z-factor | Hall-Yarborough (1974) — Newton-Raphson |
| Gas FVF (Bg) | Real gas law |
| Pseudo-critical props | Standing (1977) |
| Pressure traverse | Poettmann-Carpenter (1952) |
| Friction factor | Economides et al. (1994) curve fit |

## Quick start

### Single prediction
```python
from predict import predict_THP

result = predict_THP(
    QL=330,        # Liquid rate, STB/day
    WOR=1.5,       # Water-oil ratio
    GLR=273,       # Gas-liquid ratio, scf/STB
    oil_sg=0.85,   # Oil specific gravity
    water_sg=1.05, # Water specific gravity
    gas_sg=0.75,   # Gas specific gravity
    T=150,         # Avg wellbore temperature, °F
    API=35,        # API gravity
    Bw=1.01,       # Water FVF, bbl/STB
    d=2.441,       # Tubing ID, inches
    depth=5000,    # Well depth, ft
    Pwf=1000,      # Bottom-hole flowing pressure, psia
    method="ml"    # "ml" or "physics"
)

print(result)
# {'THP': 88.3, 'method': 'ml', 'confidence': 'high', 'out_of_range': []}
```

### Compare ML vs physics engine
```python
from predict import compare_methods

result = compare_methods(
    QL=500, WOR=1.0, GLR=350, oil_sg=0.85, water_sg=1.05,
    gas_sg=0.72, T=150, API=35, Bw=1.01, d=2.441,
    depth=5000, Pwf=800
)
print(result)
```

## Input parameter ranges (training data)

| Parameter | Min | Max | Unit |
|---|---|---|---|
| Liquid rate (QL) | 100 | 1500 | STB/day |
| Water-oil ratio (WOR) | 0.0 | 5.0 | STB/STB |
| Gas-liquid ratio (GLR) | 100 | 800 | scf/STB |
| Oil specific gravity | 0.80 | 0.90 | — |
| Gas specific gravity | 0.65 | 0.80 | — |
| Water specific gravity | 1.03 | 1.07 | — |
| Temperature | 100 | 200 | °F |
| API gravity | 25 | 45 | °API |
| Water FVF (Bw) | 1.00 | 1.02 | bbl/STB |
| Tubing ID (d) | 1.995 | 3.476 | inches |
| Well depth | 2000 | 8000 | ft |
| Bottom-hole flowing pressure (Pwf) | 200 | 2000 | psia |

Predictions outside these ranges are flagged with reduced confidence.

## Known limitations

- Training data is entirely synthetic — external validation against real well data is ongoing.
- The physics engine assumes a uniform wellbore temperature (no temperature gradient).
- The Poettmann-Carpenter method is most accurate for flowing wells without gas lift.
- Hall-Yarborough z-factor produces values ~0.007 higher than Standing-Katz chart readings
  at Ppr ≈ 1.4–1.5, Tpr ≈ 1.5. This is documented in `validation_note.md`.
